# FinSight — AI Personal Finance Intelligence Platform

A personal-finance app that turns raw bank transactions into analytics, forecasts and
natural-language answers. The core design rule: **plain code does every calculation;
machine learning handles prediction; the LLM only understands questions and explains.
The LLM never computes a number.**

> Demo data is synthetic (generated by `backend/data/generate_dataset.py`). Nothing here is
> financial advice.

## What it does

| Tab | What you get | Type of output |
|---|---|---|
| Dashboard | Income, expenses, savings rate, category breakdown, 6-month trend, top merchants | **Actual** |
| Transactions | CSV import (duplicate-safe), search/filter, edit category, auto-categorization | **Actual** |
| Budgets & Goals | Budget utilisation, savings-goal progress and time estimate | **Actual** + **Projected** estimate |
| Insights | Recurring/subscription detection, spending-leak alerts, next-month forecast | **Actual** (detected) + **Projected** |
| Ask FinSight | Chat agent that answers by calling tools on your real data | **AI-generated**, sources shown ("Data from: …") |
| What-If | "What if I cut food 20%?", "save ₹5,000 more", "cancel Netflix" | **Scenario** (AI picks parameters, backend calculates) |
| Learn | Finance-education Q&A using RAG over 6 short notes, with sources | **AI-generated**, grounded in notes |

Every screen carries coloured badges (Actual / Projected / Scenario / AI-generated) plus a
legend under the nav bar, so the four kinds of content are never confused.

## Architecture

```
React + Vite + TypeScript + Tailwind + Recharts          (frontend/)
                     │  REST / JSON
                  FastAPI                                 (backend/api)
                     │
   ┌─────────────────┼──────────────────────────┐
   │                 │                          │
 services/         ml/                         ai/
 (deterministic    categorization.py           tools.py     8 tools wrapping services
  business logic)  forecasting.py              agent.py     Gemini + automatic tool calling
 analytics         (rules → TF-IDF+LogReg;     scenario_parser.py  LLM → validated JSON params
 subscriptions      linear regression)         rag.py       chunk → embed → cosine search → answer
 leaks, budgets,                                    │
 savings, forecast,                            Gemini API (free tier)
 scenarios                │
   └──────────┬───────────┘
           SQLite (SQLAlchemy)
```

### What is plain code vs ML vs GenAI

| Layer | Used for | Never used for |
|---|---|---|
| **Plain backend code** (`services/`) | All sums, percentages, comparisons, recurring-payment detection, budget maths, scenario maths, goal timelines | — |
| **ML** (`ml/`) | Transaction categorization (rules first, TF-IDF + logistic regression when rules don't match); next-month forecast (linear regression, falls back to a simple average when there is too little history) | Anything that a simple rule can do exactly |
| **GenAI** (`ai/`) | Choosing which tool answers a question; turning a sentence into scenario parameters (structured JSON); writing answers from retrieved notes | Computing or inventing any financial figure |

## Setup

Requirements: Python 3.11+, Node 20+.

```bash
# 1. Backend (run everything from the finsight/ folder)
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt

cp .env.example .env                 # then paste your key after GEMINI_API_KEY=
                                     # free key: https://aistudio.google.com/apikey
uvicorn backend.main:app --reload    # http://localhost:8000  (API docs at /docs)

# 2. Frontend (second terminal)
cd frontend
npm install
npm run dev                          # http://localhost:5173
```

Without a Gemini key everything works except the three AI tabs, which show a clear message.

**Loading data:** Transactions tab → *Import CSV* → `backend/data/sample_uncategorized.csv`
(305 rows, many with blank categories, to show auto-categorization).
`backend/data/transactions.csv` is the same data fully labelled.

## Check everything works

```bash
python demo_check.py            # backend flows + AI flows (if GEMINI_API_KEY is set)
python demo_check.py --no-ai    # backend only
```

Runs on a throwaway database (your data is never touched) and prints PASS / FAIL / WARN.
Run it before every demo.

## Known limitations (be upfront about these)

- **Synthetic, single-user data**; no login. It is a demo, not a production system.
- **Chat has no memory:** each question is independent, so follow-ups like "and last month?" need the full question.
- **Free-tier Gemini** has rate limits, and Google may use free-tier prompts to improve its models (fine for synthetic data).
- **The finance notes were written for this project.** Check them against official material (e.g. RBI or SEBI investor-education pages) before calling them authoritative.
- **Categorization has no LLM fallback yet.** Merchants that neither rules nor ML are confident about stay "Uncategorized" (by design: it prefers no label to a wrong one).
- **"Overlapping subscriptions" is a category-level heuristic**, so it can flag legitimately different services in the same category.
- **The forecast is a linear trend on ~6 points.** It is a projection, and is labelled as one.
- **SQLite** is chosen for a single-user demo; production would use PostgreSQL (one connection-string change via SQLAlchemy).
